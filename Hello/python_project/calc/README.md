# Калькулятор на Python и Flask 🧮

Учебный веб-калькулятор, созданный для практики **Python**, **Flask**, **HTML**, **CSS** и **JavaScript**.

Главный принцип проекта: **вычисления выполняются на Python**, а JavaScript отвечает за взаимодействие пользователя с интерфейсом и передачу данных на сервер.

> **Состояние документа:** структура файлов и описание проекта сверены с текущей версией 5 ноября 2026 года.

## Что уже реализовано

- Веб-страница калькулятора с экраном ввода и кнопками.
- Тёмное оформление интерфейса на CSS Grid.
- Основная панель с цифрами и арифметическими операциями.
- Разметка панели научных функций.
- Ввод выражения с кнопок и ручной ввод в текстовое поле с клавиатуры.
- Отправка выражения на сервер без перезагрузки страницы при нажатии `=` через `fetch()`.
- Обработка `POST`-запроса на маршруте `/calculate`.
- Передача выражения и получение результата в формате JSON.
- Базовые арифметические операции на стороне Python.
- Кнопка `AC` для очистки экрана.
- Начало нового ввода при нажатии цифровой кнопки после получения результата.
- Сообщения о некоторых ошибках ввода и делении на ноль.

## Вычисления на Python

Функция `calculating(expression)` находится в `app.py`. Она принимает выражение, выделяет числа и оператор, затем выполняет соответствующую операцию через модуль `operator`.

В текущей версии поддерживается вычисление с **двумя числами и одним оператором**, разделёнными пробелами:

```text
10 + 5
8 / 2
2 ** 3
-4 + 6
1.5 + 2
```

| Оператор | Операция |
| --- | --- |
| `+` | Сложение |
| `-` | Вычитание |
| `*` | Умножение |
| `/` | Деление |
| `//` | Деление с округлением вниз |
| `**` | Возведение в степень |
| `%` | Остаток от деления |

Числа преобразуются в `float`, поэтому поддерживаются отрицательные и дробные значения. Для дробных чисел в выражении используется точка.

Выражения с несколькими операциями, приоритетом действий и скобками пока не поддерживаются.

## Интерфейс

Калькулятор состоит из экрана, панели научных функций, цифровой панели и столбца основных операций. В разметке также предусмотрены кнопки `±`, удаления символа, степеней, корней, тригонометрических функций и памяти.

Наличие кнопки в разметке не означает, что её функция уже реализована. Логика научных функций, памяти и удаления символа остаётся в планах разработки.

Текущий внешний вид задан в `static/style_2.css`. Файл `static/style_1.css` сохранён как предыдущий вариант оформления и сейчас не подключён. Переключателя тем пока нет.

## Как это работает

1. Пользователь вводит выражение в интерфейсе и нажимает `=`.
2. JavaScript отправляет `POST /calculate` с JSON-данными:

   ```json
   {"expression": "10 + 5"}
   ```

3. Flask получает выражение и передаёт его функции `calculating(expression)`.
4. Python возвращает результат или сообщение об ошибке.
5. Flask отправляет JSON-ответ:

   ```json
   {"result": 15.0}
   ```

6. JavaScript показывает полученный результат на экране калькулятора.

### Маршруты Flask

| Маршрут | Метод | Назначение |
| --- | --- | --- |
| `/` | `GET` | Показать страницу калькулятора |
| `/` | `POST` | Обработать отправку HTML-формы и вернуть страницу с результатом |
| `/calculate` | `POST` | Получить выражение в JSON и вернуть результат в JSON |

## Как запустить проект локально

1. Установить Python 3.
2. Открыть папку `calc` в VS Code или терминале.
3. При необходимости создать и активировать виртуальное окружение Python.
4. Установить Flask:

   ```bash
   python -m pip install flask
   ```

5. Запустить приложение:

   ```bash
   python app.py
   ```

6. Открыть в браузере [http://127.0.0.1:5000](http://127.0.0.1:5000).

Приложение запускается в режиме разработки Flask с `debug=True`.
